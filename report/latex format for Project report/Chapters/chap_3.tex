\chapter{Dataset}
\justify

The CLEF JOKER Task 1 dataset consists of short English humorous snippets designed for ad-hoc retrieval.

\section{Data Composition}
\begin{itemize}
    \item Corpus size: 77,658 documents
    \item Training queries: 12
    \item Test queries: 219
    \item Training relevance labels (qrels): 660
\end{itemize}

Each corpus record contains a document identifier and a short text field. Query length is intentionally small (1--3 terms), making retrieval highly ambiguous and challenging.
