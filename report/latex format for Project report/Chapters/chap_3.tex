\section{CLEF JOKER 2025 Task 1 Overview}

JOKER (Wordplay \& Humour Modelling) is a recurring lab at the Conference and Labs of the Evaluation Forum (CLEF). Task 1 is an ad-hoc information retrieval task: given a short query, retrieve and rank up to 1000 documents from a fixed humor corpus. The task is evaluated using TREC-style relevance judgments and the primary metric MAP@1000.

\section{Data Files and Format}

The dataset consists of three JSON files:

\begin{itemize}
    \item \textbf{Corpus} (\texttt{joker\_task1\_retrieval\_corpus25\_EN.json}): A collection of 77,658 short English humorous text fragments. Each entry is a JSON object with fields \texttt{docid} (unique integer) and \texttt{text} (the document string).

    \item \textbf{Queries} (\texttt{joker\_task1\_retrieval\_queries\_\{train|test\}25\_EN.json}): Each entry has fields \texttt{qid} (unique integer) and \texttt{query} (the query string). Training set contains 12 queries; test set contains 219 queries.

    \item \textbf{Relevance Judgments / Qrels} (\texttt{joker\_task1\_retrieval\_qrels\_train25\_EN.json}): Each entry has fields \texttt{qid}, \texttt{docid}, and \texttt{qrel} (binary: 1 = relevant). Only training-set judgments are released; the test set is evaluated by CLEF organizers.
\end{itemize}

\section{Corpus Characteristics}

The corpus consists of short humorous English text fragments---jokes, puns, humorous observations, and wordplay snippets. Key characteristics:

\begin{itemize}
    \item \textbf{Document length:} Median 18 words, mean 20.4 words. 69\% of documents are in the 11--30 word range, reflecting the concise nature of joke formats.
    \item \textbf{Content type:} Single-sentence jokes, question-answer format jokes (setup + punchline), and short humorous narratives.
    \item \textbf{Humor mechanisms:} Puns (phonetic/semantic ambiguity), wordplay (polysemy exploitation), incongruity (unexpected associations), and dark humor (morbid or absurdist content).
\end{itemize}

\section{Task Characteristics and Challenges}

\subsection{Query Brevity}
Of the 231 total queries, 225 (97.4\%) are single words, 5 are two-word phrases, and only 1 is a three-word phrase. This extreme brevity means there is almost no explicit lexical context to guide retrieval. Standard BM25 retrieval matches documents that contain the query word, but most relevant documents contain the query theme through indirect wordplay, not through direct term mention.

\subsection{Semantic Indirection via Humor}
Humor links are indirect and require world knowledge. For the query ``\textit{math}'', a relevant document might be: \textit{``A lawyer was defending a math teacher. He had to sum up.''} The humor is in the double meaning of ``sum up'' (legal summary + arithmetic sum). No part of this document is a direct lexical match to ``math'' except the word itself.

\subsection{Extremely Small Training Set}
Only 12 training queries with binary relevance judgments are available. This severely limits any supervised approach. An XGBoost model trained on 12 queries must use heavy regularization and leave-one-query-out cross-validation to avoid overfitting.

\subsection{Label Imbalance}
The number of relevant documents per training query ranges from 4 to 364, creating significant imbalance both within queries (positive-to-corpus ratio is $\ll 1\%$) and across queries. Any learning-to-rank approach must account for this distribution.
