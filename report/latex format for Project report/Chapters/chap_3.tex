\chapter{Dataset}
The retrieval corpus used in this project contains 77,658 short humorous snippets and supports the CLEF JOKER 2025 Task 1 setup. The train split includes 12 queries with 660 relevance judgments, while the test split has 219 short keyword-style queries.
