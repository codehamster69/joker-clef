\chapter{Methodology and Experimental Setup}
\justify
The proposed system uses a seven-stage ranking pipeline.

\section{Pipeline Stages}
\begin{enumerate}
    \item BM25 + character n-gram lexical retrieval.
    \item Dense retrieval using BGE embeddings and FAISS.
    \item Reciprocal Rank Fusion (RRF) for candidate merging.
    \item Feature extraction (lexical, structural, and humor-aware).
    \item Cross-encoder reranking on top candidates.
    \item RoBERTa humor-pair scoring.
    \item Final rank fusion using static weights or XGBoost L2R.
\end{enumerate}

\section{Evaluation Protocol}
Evaluation follows MAP@1000 on official task format outputs. Development emphasizes robustness under extremely small training-query count and highly sparse query semantics.
