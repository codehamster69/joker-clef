\justify

The proposed system follows a multi-stage architecture that progressively improves recall and precision.

\section{Pipeline Overview}
\begin{enumerate}
    \item Lexical retrieval using BM25 with character n-gram support and optional pseudo relevance feedback.
    \item Dense retrieval using BAAI/bge-base-en-v1.5 embeddings with FAISS indexing.
    \item Reciprocal Rank Fusion to merge lexical and dense candidate lists.
    \item Feature extraction (lexical, semantic, and humor-aware signals).
    \item Cross-encoder reranking for fine-grained relevance estimation.
    \item Humor pair classifier scoring using RoBERTa.
    \item Final ranking using weighted fusion or XGBoost learning-to-rank.
\end{enumerate}
