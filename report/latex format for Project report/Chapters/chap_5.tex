\section{Ablation Insights}
\begin{itemize}
    \item Removing PRF reduces recall for short ambiguous queries.
    \item Removing dense retrieval hurts semantic matching for indirect humor cues.
    \item Removing L2R causes less stable ranking across queries.
\end{itemize}

\section{Discussion}
The project demonstrates that humor-aware retrieval requires hybrid ranking signals. Pure lexical or pure dense strategies are insufficient alone; multi-signal fusion is essential for best effectiveness.
