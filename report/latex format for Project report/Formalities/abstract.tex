\begin{center}
    \Large \textbf{\uppercase{Abstract}}
\end{center}

\vspace{2\baselineskip}
\justify

This report presents the design, implementation, and evaluation of a \textbf{humor-aware information retrieval system} developed for \textbf{JOKER @ CLEF 2025 Task 1}. The task requires a system to retrieve humorous and topically relevant text snippets from a corpus of 77,658 short documents given extremely short clue-style queries (typically a single word such as \textit{``colors''}, \textit{``death''}, or \textit{``math''}). The primary evaluation metric is Mean Average Precision at rank 1000 (MAP@1000).

The core challenge of this task is the \textit{semantic indirection} inherent in humor: a document is relevant not because it explicitly mentions the query word, but because it exploits that word for comedic effect through puns, wordplay, or incongruity. Standard keyword-based retrieval fails in this setting because the connection between query and relevant joke is often latent and context-dependent.

The proposed system follows a \textbf{seven-stage multi-signal pipeline}. The first stage performs high-recall lexical retrieval using BM25 augmented with character n-gram TF-IDF and optional Pseudo-Relevance Feedback (RM3) for query expansion. The second stage performs semantic dense retrieval using the \texttt{BAAI/bge-base-en-v1.5} bi-encoder model with a pre-built FAISS index. Candidate lists from both stages are merged using Reciprocal Rank Fusion (RRF). The merged candidates are then re-scored using a cross-encoder (\texttt{ms-marco-MiniLM-L12-v2}) and a task-specific humor pair classifier based on fine-tuned \texttt{roberta-base}. Finally, a 16-dimensional feature vector per candidate is used to train an XGBoost Learning-to-Rank (L2R) model that replaces static fusion weights with adaptively learned ones.

Experiments on the 12 training queries demonstrate substantial improvements over the lexical baseline. The full optimised system achieves \textbf{MAP@1000 = 0.486}, \textbf{MRR = 0.917}, and \textbf{NDCG@1000 = 0.646}, representing a 203\% relative improvement over a pure BM25 baseline and exceeding the published CLEF 2025 state-of-the-art on the training split.

The report details dataset characteristics, the full methodology with mathematical formulations, component-wise ablation, a reranker model comparison, all evaluation metrics, and directions for future improvement.
